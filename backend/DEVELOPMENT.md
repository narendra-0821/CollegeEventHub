### Getting Started

first install "npm install" in backend, frontend

if "npm install" gives error then run "npm install --legacy-peer-deps"

second copy all the below commands and install in backend, frontend and auth-system folders... 

npm install dotenv
npm install mongoose
npm install axios
npm list react-router-dom
npm install --save-dev @types/jsonwebtoken


To run backend, frontend  simultaneously:
go to backend folder and run below command-

npm run dev


This will start:
- Backend server on `http://localhost:4000`
- Frontend dev server on `http://localhost:5173`
- Auth app (Next.js) on `http://localhost:3000`
